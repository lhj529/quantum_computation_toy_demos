1我们要实现什么：ZZ($\gamma$) 门

QAOA 的 Cost Hamiltonian（MaxCut 问题）是图上所有边的 Z⊗Z 项之和：

Cost Hamiltonian
$$H_C = \sum_{(i,j) \in E} Z_i Z_j \qquad\text{(每条边贡献一个 ZZ)}$$

其时间演化为：

Cost Unitary（目标）
$$U_C(\gamma) = e^{-i\gamma H_C} = \prod_{(i,j)\in E} \underbrace{e^{-i\gamma\, Z_i Z_j / 2}}_{\text{ZZ}(\gamma)\;\text{门}}$$
核心任务：用硬件原生门（CZ 和单 qubit 旋转）实现两 qubit 门 ZZ($\gamma$) = $e^{-i\gamma\, Z\otimes Z/2}$。

用 Bloch 球的语言说：ZZ($\gamma$) 是两个 qubit 之间的条件相位旋转——当两个 qubit 的 Z 分量同号时积累 $-\gamma/2$ 相位，异号时积累 $+\gamma/2$ 相位。

2第一步：ZZ 通过 CNOT + Rz + CNOT

最著名也最核心的恒等式——CNOT 三明治：在 target qubit 上施加 $R_z(\gamma)$，两侧各用一个 CNOT 包裹。

ZZ(γ) = CNOT · (I⊗Rz(γ)) · CNOT ctrl: ──●──────────────●── │ │ targ: ──⊕──Rz(γ)──⊕──
电路图 1：ZZ(γ) 的 CNOT 三明治分解

为什么这个恒等式成立？在计算基下，CNOT 的行为是 $|x,y\rangle \mapsto |x, x\oplus y\rangle$。来看它对算符的共轭作用：

推导

记 ctrl = qubit 1，targ = qubit 2。CNOT = $|0\rangle\langle 0| \otimes I + |1\rangle\langle 1| \otimes X$。

设 target 上的 $R_z(\gamma) = e^{-i\gamma Z_2/2} = \cos(\gamma/2)\, I - i\sin(\gamma/2)\, Z_2$。

CNOT 把 $Z_2$ 共轭为 $Z_1Z_2$（这是 CNOT 的经典性质：它将 target 上的 Z 错误传播到 ctrl 上）：

核心恒等式
$$\text{CNOT} \cdot (I \otimes Z) \cdot \text{CNOT} = Z \otimes Z$$

由此立刻得到指数形式：

$$\text{CNOT} \cdot (I \otimes R_z(\gamma)) \cdot \text{CNOT} = \text{CNOT} \cdot e^{-i\gamma\, I\otimes Z/2} \cdot \text{CNOT}$$ $$= \exp\!\big(-i\gamma\, \text{CNOT} \cdot (I\otimes Z) \cdot \text{CNOT} / 2\big)$$ $$= e^{-i\gamma\, Z\otimes Z/2} = \text{ZZ}(\gamma)$$
物理直觉：CNOT 把 target qubit 的相位信息拷贝到 ctrl qubit 上——于是原本只作用在一个 qubit 上的 $R_z$ 变成了两个 qubit 联合的条件相位。

重要：所有 ZZ 门互相可交换。因为 $Z_iZ_j$ 都是对角矩阵，不同边上的 ZZ 项对易。因此：

$$\prod_{(i,j)\in E} e^{-i\gamma\, Z_i Z_j/2} $$ 对每条边独立分解，不需要在意顺序——这是并行化的数学基础。

3第二步：CNOT 通过 H + CZ + H

上面一步把 ZZ 分解成了 CNOT + Rz。但中性原子硬件没有 CNOT——它只有 CZ。
好消息是，CNOT = H(target) · CZ · H(target)，这个恒等式是量子计算教科书的第一页。

CNOT = (I⊗H) · CZ · (I⊗H) ctrl: ──●──────────●── │ │ targ: ──H──◯──H──
电路图 2：CNOT 分解为 CZ + H（◯ = CZ）
CNOT vs CZ 的关系
$$X = HZH \quad\Longrightarrow\quad \text{CNOT} = (I\otimes H) \cdot \text{CZ} \cdot (I\otimes H)$$

直观看：CZ 在目标 qubit 是 |1⟩ 时给条件相位 −1。CNOT 在控制 qubit 是 |1⟩ 时翻转目标。$X = HZH$（H 把 Z 特征基旋转到 X 特征基），把这个代进去：CZ 的控制端不变，target 端的 Z 变成 X → 条件翻转 = CNOT。

从 QAOA 电路的角度，CZ 已经是硬件原生门，H 可以通过 $U(\pi/2, 0, \pi)$ 实现（也即单 qubit 旋转，同样是原生的）。这意味着：两步分解后，ZZ(γ) 中不再包含任何非原生门。

4完整展开：ZZ($\gamma$) 分解的全貌

把两步串起来，得到 ZZ($\gamma$) 的完整五门分解：

ZZ(γ) ⟶ CNOT · Rz(γ) · CNOT
↓ 展开每个 CNOT
H · CZ · H · Rz(γ) · H · CZ · H
绿色 = 硬件原生门（CZ 和单 qubit 旋转）
ZZ(γ) 完整分解 —— 5 个原生门序列 q0 (ctrl): ──────●──────────────────●────── │ │ q1 (targ): ──H──◯──H──Rz(γ)──H──◯──H── HH = I 抵消！
电路图 3：ZZ(γ) 的五门分解（中间 H 不抵消因为它们夹着 Rz）
⚠ 注意：中间的两个 H 看起来相邻，但它们中间夹着 Rz(γ)，所以不能轻易合并成 I。实际上 $HR_z(\gamma)H = R_x(\gamma)$，这里 H-Rz-H 构成的是 X 基下的旋转——这正是 ZZ 门在两个 qubit 之间传递相位的机制。

Bloqade 中为何合并了 H

在实际代码中，中间的 $HR_z(\gamma)H = R_x(\gamma)$ 并不是最优的（因为硬件原生支持任意 U 旋转）。Bloqade 的做法是：保留外侧 H 用于 CZ 的基变换，但 主动避开 中间两次 H 的冗余。观察：

Bloqade 优化版（parallel_cz_phase） ctrls: ──●──────────────────●────── │ │ qargs: ──H──◯──H──Rz(γ)──H──◯──H──
电路图 4：标准五门方案（与 Bloqade 等价）

而 Bloqade 的 parallel_cz_phase 写了两步 parallel_cx + 一步 parallel.rz，意味着它把中间的 $H\cdot R_z(\gamma)\cdot H$ 隐含在 CNOT 分解的自动合并中了——编译器会优化，所以手写代码不需要显式展平到五门。

5Bloqade 代码对应关系

回到你的 Bloqade SIMD 代码，逐函数映射：

代码函数数学定义对应电路
parallel_h(qargs) $U(\frac{\pi}{2}, 0, \pi) = H$ 单 qubit Hadamard（硬件原生）
parallel_cx(ctrls, qargs) H(target) · CZ · H(target) CNOT = 第三节图 2 的分解
parallel_cz_phase(ctrls, qargs, gamma) CNOT · Rz(γ) · CNOT ZZ(γ) = 第二节图 1 的分解
qasm2.parallel.u(all_qubits, theta=beta, ...) $U(\beta, 0, 0) = R_y(\beta)$ Mixer: 单 qubit 旋转（硬件原生）

调用链：

parallel_cz_phase 调用 parallel_cx 调用 parallel_h + cz 调用 parallel_h + rz + parallel_cx （再展开）...

这样设计的好处：调用一次 parallel_cz_phase 就是一次完整的 ZZ(γ)，而且 SIMD 并行——同一颜色组的所有边一起做。

6为什么非这样做不可

三层递进逻辑：

层级问 题答 案
物理层 硬件有什么门？ 中性原子：CZ（Rydberg 阻塞）+ 任意 U(θ,φ,λ)（激光脉冲）。
没有 CNOT，没有 原生 ZZ。
数学层 算法需要什么门？ QAOA 的 cost unitary = 每条边上 $e^{-i\gamma Z_i Z_j/2}$。
必须用 ZZ(γ) 两 qubit 门。
编译层 怎么把算法翻译成硬件门？ ① ZZ(γ) → CNOT + Rz(γ) + CNOT（本文第 2 节）
② CNOT → H + CZ + H（本文第 3 节）
⇒ ZZ(γ) 最终全由原生门构成
总结：这不是"多此一举"——这是量子编译的本质工作。算法用高层逻辑门表达（ZZ），编译器把它们翻译成硬件能听懂的原生门序列（CZ + U）。分解越高效，电路越短；电路越短，噪声影响越小。

回到代码中，parallel_cz_phase 封装了这全部三步——
对上层调用者（kernel 里的 QAOA 循环），它就是一个可以直接用的 ZZ(γ) 原语。
