- This project utilizes the `bloqade` library to implement QRC  encoding for handwritten datasets. 

- Primary goal ： to convert handwritten image data into an efficient and error-resistant encoded format

- The project currently supports popular handwritten datasets (e.g., MNIST, EMNIST) and provides a toolchain for encoding and decoding operations. Additionally, the encoded output can be seamlessly integrated into downstream data processing pipelines, such as training Support Vector Machines (SVM) for classification or other machine learning models, enabling end-to-end handwritten digit analysis workflows.
